# Empyrion Trade Ledger

**[Download on Nexus Mods](https://www.nexusmods.com/empyriongalacticsurvival/mods/199)**

Trade Ledger is an in-game journal for Empyrion and Reforged Eden 2. It remembers
vendor prices and stock, NPC requests, discovered places and deposits, and personal
devices that need servicing. Search your observations and mark destinations without
keeping everything in your head. It does not buy, move items or explore for you.

**Version:** 1.0 (Empyrion 1.20.1 build 5232 / RE2 Build 46 reference setup).
Windows client; single-player oriented. Future game builds depend on compatible
native interfaces; multiplayer is not certified.

## Install and open

1. Close Empyrion.
2. Copy the ZIP's **TradeLedger** folder into **Content/Mods** in the game folder.
   To update, copy into the same folder and replace the supplied files.
3. Start the game and press **] (RightBracket)**. Escape or Close dismisses it.

Keep the supplied settings file. Only if you customized its service options do you
need to preserve your old copy. Updating mod files leaves journal records in
**<current save>/Mods/TradeLedger/TradeLedger.sqlite** intact. Do not delete the
whole mod folder if you want to keep its logs. No installation script is required.

Prices and stock are last observed, not guaranteed current. Missing observations
remain unknown. [Installation and troubleshooting](docs/release/README.md) |
[Places guide](docs/places-context.md)
