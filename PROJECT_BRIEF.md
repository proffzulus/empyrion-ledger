# Trade Ledger source overview

Client-side personal economic/discovery memory for Empyrion and Reforged Eden 2.
Record only legitimately observed markets, shown requests and discovered places;
retain unknown versus zero, exact save/player/instance identity, passive inventory
boundaries, native-backup publication barriers and bounded main-thread work.
This is not a production planner, autonomous player or universe reveal.

See README.md, CONTRIBUTING.md and docs/BUILDING.md. Historical ProbeB namespaces
and test assembly names are implementation identifiers, not a second installed mod.
Build/test scripts only write repository-owned outputs. Installation is a separate,
explicit guarded command and is never a build or test side effect.
